# 关卡结果可视化策划

版本：1.1。覆盖全部 55 关。本文件描述将来游戏的界面与反馈规则，配套 [交互示例](visualization-preview.html) 只演示局部计算和画面联动，不代表游戏或训练后端已经实现。

每关让玩家同时看见三件事：机器当前产出的结果、这个结果由哪里产生、自己改动后发生了什么。局部计算用数值与索引解释，大型项目再使用曲线、决策区域、特征图和错分样本。四项逐关规格分别约定主画面、操作联动、失败定位和通关后保留的成果。

## 工作台的共同布局

左侧是可收起的任务与短文卡，中间是接线工作台，右侧是本关结果面板，下方是单步、运行、暂停和当前阶段。先给本关最重要的一张图，选择节点或样本才展开局部信息。初学者不必同时面对所有损失、权重、激活和梯度图。

在封装与工程关中，工作台和分拣站联动：一个样本的计算结果决定它实际进入哪个出口；打开盒子可回到内部节点。这给数值结果一个可使用的用途，通关后保存的机器也能再次运行。

## 数值与画面的共同规则

| 画面对象 | 必须遵守的语义 |
| --- | --- |
| 连线与计算步 | 正向和反向使用不同箭头样式及文字；动画只提示已执行阶段，不把视觉移动速度当作梯度大小 |
| 数值与梯度 | 同时显示符号和数值；正负贡献画在零轴两侧，梯度与参数更新量分开标记 |
| 检查状态 | 成功、失败、未计算、缺输入分开标记；不能将未计算或缺失值显示成零 |
| 形状与索引 | 轴名、尺寸、样本身份可见；小例子展示全部元素，大张量先展示所选切片 |
| 热图 | 带图例和真实数值范围；对照两张图时默认共享色阶；独立缩放必须注明；ReLU 零值和负梯度不使用相同语义 |
| 特征与响应 | 特征图表示核响应，不能把亮格直接标成模型注意力或正确依据；解释到实际窗口贡献即可 |
| 原始分数与概率 | 原始分数可负且不必和为一；Softmax 后才是预测分布，概率条不被表述为已校准的识别正确率 |
| 曲线 | 训练步是主要横轴，实际耗时单独列出；批次损失和整组验证损失明确标注，不能混接成同一系列 |
| 训练数据与快照 | 所有联动画面来自同一个模型版本、运行编号和选定样本；载入旧快照后所有相关画面一并更新 |
| 数据角色 | 训练、验证、测试及个人画板分别标明；测试在冻结后开放，个人笔迹指标不混入标准测试指标 |
| 能力限制与诊断 | C01 按观察任务解锁；E06 按检查与受控比较解锁；不给不可能目标或偶然指标改善做成功动画 |
| 可访问性 | 颜色之外还用符号、形状、编号和文字；支持减弱动画、暂停查看及键盘选样本 |

## 关键数值与索引约定

灰度图采用明确的行列坐标；张量层约定批次、空间和通道轴，示例可采用 B×H×W×C。二维网格的行优先编号在所有重排示意中一致。Flatten 保留 B，把 H×W×C 合成特征轴。实现若采用不同内部布局，界面必须展示映射，不能让端口轴名随执行后端改变。

矩阵示例使用 X 的输入轴与 W 的输出轴明确相接。Y=XW 且上游梯度为 G 时，反向模板展示 dX=G·Wᵀ、dW=Xᵀ·G；玩家可以选一个元素查看贡献来源。这里的矩阵行在 D04 先作为多组向量布局，在 D06 才正式解释为样本批次。

F03 必须同时展示核梯度的跨位置求和和输入梯度的重叠放回累加。F04 若启用偏置，复用每个输出通道一个偏置和空间贡献求和的规则。F05 原型可先支持对称零填充 P、核大小 K、步幅 S，输出长度为向下取整后的 (输入长度+2P-K)/S 再加一；先通过实际窗口计数理解，公式作为帮助。

ReLU 零点梯度取零；Argmax 与 MaxPool 并列最大值取约定索引顺序中的第一个。S02 固定使用 v=βv+g、w=w−ηv 这一套动量约定。S04 的标准化明确为减训练均值后除以训练总体标准差，零标准差使用固定安全尺度一；统计来源在面板上可查。

## 大规模训练如何保持可看懂

观察模式按节点或训练阶段推进；快速模式仍使用同一语义的图和权重，只减少动画。曲线按真实训练步采样，保留任务线、拐点和非有限值；训练过程中逐帧显示全部权重没有教学价值。玩家暂停后可以选择一个样本、层或通道，查看同一快照的局部结果。

建议先以每秒五至十次的统计刷新和按需切片作为原型起点，实际频率经过性能测试确定。动画帧数、计算步数和当前模型版本分别管理。缩略特征图或参数统计若经过采样，必须标明采样范围。

结果事件至少包含运行编号、模型版本、训练步、阶段、数据角色、样本身份、节点身份、轴名、形状、数值或切片、数值单位、当前检查结果。训练视图还记录随机种子、预算、执行后端和快照；前端不得将不同版本的数据拼成一张解释图。

## 每关的四项画面规格

### 序章 让机器动起来

#### P00 停摆的分拣站

**主要结果：** 分拣站的样本卡与两个出口；左右并列未训练、训练后的同一批结果，附正确数与实际权重。

**操作联动：** 点选样本联动两份预测；拖训练步回放权重和出口改变。

**失败定位：** 错分卡保留真实类别与预测出口；训练无改善时提示重置同一参考模型重试。

**通关成果：** 保存前后对照，站内亮起一条已修复线路；点击可重放体验。

### 计算工坊

#### A01 看见信号

**主要结果：** 端口、线与数字显示器；一份样本只在当前计算步高亮实际经过的节点。

**操作联动：** 切样本或单步，选中线查看数值与来源。

**失败定位：** 断开的必需端口显示空值和未连接标签，禁止把空值画成零。

**通关成果：** 三张样本检查卡全部通过，工作台保存有效接线。

#### A02 校准放大器

**主要结果：** 输入横轴、输出纵轴的直线与期望点；旋钮旁显示权重，样本表显示输出。

**操作联动：** 拖权重同步改变斜率；负权重时箭头与数值显示反号。

**失败定位：** 各样本显示带符号残差与未吻合点，指出不能只校准一个重量。

**通关成果：** 冻结通过时的斜率和旋钮，附新输入通过记录。

#### A03 修正零点

**主要结果：** 期望点、当前直线与零输入标记；纵向位移标尺显示偏置。

**操作联动：** 拖偏置，整条线平移；点选零输入确认截距。

**失败定位：** 保留调整前的淡色线，显示各样本同方向偏移。

**通关成果：** 零点与多输入检查通过，保存偏置插槽。

#### A04 混合两个信号

**主要结果：** 二维输入点和输出读数；贡献条并列显示 w1×x1、w2×x2、b 与总和。

**操作联动：** 固定一个输入只调另一个；点贡献条定位对应乘法器。

**失败定位：** 输出与目标差值明确列出；一条贡献异常时高亮其输入和参数。

**通关成果：** 保存展开的加权单元和输入规格，后续封装关引用同一结构。

#### A05 不会抵消的误差计

**主要结果：** 残差横轴与半平方损失抛物线；当前点与正负同幅对照点同时显示。

**操作联动：** 拖预测或目标，同步更新残差、平方中间值和损失；切换错误求和方案。

**失败定位：** 出现负损失或正负抵消时，显示反例样本及首个不符规格的节点。

**通关成果：** 三个典型点通过并留在图上，保存可展开误差计。

#### A06 把机器装进盒子

**主要结果：** 展开子图到模块盒子的对应动画，接口名单与两个实例参数面板并排。

**操作联动：** 折叠、展开；改变一个实例旋钮，观察另一个是否变化。

**失败定位：** 漏接口显示缺失端口；误共享参数标出共同参数身份，而非只亮红色。

**通关成果：** 模块进入库，显示两个独立实例及其已通过规格。

#### A07 手动校准台

**主要结果：** 整台校准设备、逐样本损失表和平均损失分解条；四个损失到平均器可展开。

**操作联动：** 逐样本播放，调参时全部样本与平均数一起刷新。

**失败定位：** 平均与求和混淆时同时显示两数；未达规格的样本可回到对应输入。

**通关成果：** 设备在新输入上实际运行，保存接线、参数与校准报告。

#### S01 同样结果更少部件

**主要结果：** 两份结构同步计算、逐样本输出差值和部件计数。

**操作联动：** 点差值定位产生分歧的节点；切未见输入检查等价性。

**失败定位：** 减少部件但结果改变时突出反例，而非仅展示成本降低。

**通关成果：** 保存更少部件的等价模块与检查样本。

### 学习引擎

#### B01 试探一个旋钮

**主要结果：** 损失随单个参数变化的一维曲线；当前位置、微小位移和割线三角形。

**操作联动：** 控制位移大小，读取 Δ参数、Δ损失及比值；每次只动一个参数。

**失败定位：** 位移为零禁用比值；位移太大显示局部近似偏差对照，不标成真实导数。

**通关成果：** 记录几处变化率及符号，解锁反向端口并保留示例。

#### B02 加法的回路

**主要结果：** 加法器两输入微调对照；反向箭头旁直接标上游梯度与两个输出梯度。

**操作联动：** 切换非单位上游梯度，比较有限差分参考。

**失败定位：** 漏接或缩放错误的输入支路显示预计值、实际值和差值。

**通关成果：** 正负与非单位梯度检查卡通过，反向规则装入 Add。

#### B03 乘法的回路

**主要结果：** 两个输入、乘积与两条反向贡献条；显示 g×另一输入的中间乘积。

**操作联动：** 拖输入穿过零，查看反向结果的大小和符号。

**失败定位：** 将输入用反时高亮被误引用的端口，列出能区分错误的反例。

**通关成果：** 测试覆盖表通过，保存 Multiply 的反向子图。

#### B04 穿过多层机器

**主要结果：** 无分支串联计算图与步骤时间轴；正向值和反向值分两行，下游结果到达的节点才可运行。

**操作联动：** 单步反向；点节点展开局部导数和组合梯度。

**失败定位：** 提前执行的节点显示尚缺的下游结果；数值不符定位首个偏差节点。

**通关成果：** 保存调度顺序，并回放完整标量目标到输入的路径。

#### B05 两条路汇到一起

**主要结果：** 共享参数身份标签、分支图与可正可负的贡献条，总梯度位于零轴旁。

**操作联动：** 逐条启用路径；切换共享参数与独立副本。

**失败定位：** 遗漏、覆盖贡献分别显示未计入路径；重复输入的两个贡献保持独立来源标记。

**通关成果：** 各贡献与总和一致，保存共享引用和累加规则。

#### B06 沿着趋势迈一步

**主要结果：** 一维损失曲线、当前位置和更新后位置；分别标梯度方向与实际移动箭头。

**操作联动：** 先预测方向，再单步更新；切换参数查看计算式。

**失败定位：** 加减号或步长错误时显示参考更新位置；梯度与更新量不得使用同一未标注箭头。

**通关成果：** 保存 SGD 子图与一次正确更新记录。

#### B07 一步迈多远

**主要结果：** 同一起点的多条参数轨迹与损失曲线，按训练步对齐。

**操作联动：** 选择步长重跑；点训练步定位曲线和损失地形上的位置。

**失败定位：** 发散、振荡、过慢分别由真实数值和任务线标识；非有限数值明确中止。

**通关成果：** 锁定有效步长，保留一个稳定与一个不稳定对照。

#### B08 把一次变成循环

**主要结果：** 正向、清空、反向、更新四阶段环与状态表，标当前轮号和缓存所属轮号。

**操作联动：** 暂停第二轮，展开梯度槽；改变步骤顺序查看影响。

**失败定位：** 旧梯度标出产生轮次，旧缓存标出参数版本，定位遗漏的清空或重新正向。

**通关成果：** 连续更新与参考值一致，保存循环流程。

#### B09 自动校准引擎

**主要结果：** 设备运行、平均损失曲线、参数轨迹与训练阶段灯；所有曲线来自实际训练器。

**操作联动：** 训练、暂停、单步；保存载入快照，查看同一新输入结果。

**失败定位：** 曲线异常可跳回当前训练步的阶段与数值；快照载入失败显示配置差异。

**通关成果：** 整机恢复自动校准，模块库显示训练器及可复现快照。

#### S02 让步子记住方向

**主要结果：** 同起点 SGD 与动量轨迹；每步速度分解为衰减旧速度和当前梯度。

**操作联动：** 拖动量系数；重置实验查看速度是否归零。

**失败定位：** 残留速度、符号或更新错误显示两项分解和参考值。

**通关成果：** 保存正确动量更新器与固定任务对照，主线仍可沿用 SGD。

### 非线性分拣

#### C01 直线到不了的地方

**主要结果：** XOR 四点、当前直线和门槛；真实类别用形状、预测用出口边框区分。

**操作联动：** 旋转平移直线，保存两组边界并逐点比较。

**失败定位：** 不把未达百分之百画成玩家失败；高亮当前错点，展示另一边界留下的新错点。

**通关成果：** 完成观察对照后标记能力限制，并开放非线性工坊。

#### C02 让信号有一个折点

**主要结果：** 输入输出坐标系中的 ReLU 折线和当前点；分段门当前选择可见。

**操作联动：** 拖输入越过零，联动门选择、输出与曲线点。

**失败定位：** 负数错误透传或正数被截断时，显示该输入的实际和预期点。

**通关成果：** 正负与零点检查通过，保存正向部件；反向端口仍标为下一关能力。

#### C03 中间表示工作台

**主要结果：** 原始二维平面与两隐藏输出组成的中间平面，使用相同样本编号。

**操作联动：** 选同一物品时联动两个坐标；调单个单元只更新对应坐标轴。

**失败定位：** 接错中间端口时标出坐标来源；明确当前全仿射组合仍为线性。

**通关成果：** 保存两级接口与样本映射，等待接入非线性。

#### C04 折点怎样参加学习

**主要结果：** ReLU 正向折线与反向通行门；输入符号、上游梯度、回传值同时显示。

**操作联动：** 切换正负输入和不同上游梯度；零点显示采用的规则。

**失败定位：** 关闭区仍有梯度或开启区错误缩放时，对照有限差分参考；零点不用光滑参考判错。

**通关成果：** 保存可训练 ReLU，既有隐藏网络的梯度路径接通。

#### C05 非线性分拣站

**主要结果：** 真实训练得到的二维决策区域、XOR 四点、隐藏单元响应小图与损失曲线。

**操作联动：** 选训练步联动边界；选隐藏单元突出其响应区域；保存初始化对照。

**失败定位：** 错点带真实和预测标签；训练停滞时查看隐藏响应是否完全重合或 ReLU 长期关闭。

**通关成果：** 四点分类通过后，分拣站运行四件物品；保存 MLP 和权重。

#### S03 半月港湾

**主要结果：** 半月样本与真实决策区域；隐藏响应分页展示，训练验证样本用不同标记。

**操作联动：** 调隐藏宽度或选单元查看响应，观察保留样本结果。

**失败定位：** 过窄区域显示错点来源；若使用二维投影必须明确标注，不能画成完整高维空间。

**通关成果：** 保存达到目标的网络和验证边界图。

### 张量装配线

#### D01 把信号装成一排

**主要结果：** 独立数值线到带索引向量线的对应图，每个元素同时有编号与数值。

**操作联动：** 点向量元素高亮原始端口；交换顺序再拆包。

**失败定位：** 错序显示首个不匹配索引，未填元素显示缺失。

**通关成果：** 打包拆包往返检查通过，保存向量接口。

#### D02 形状拼图

**主要结果：** 二维带编号网格与一维序列联动，旁边显示形状和总元素数。

**操作联动：** 点元素追踪正向位置；给序列某位置一个梯度并反向还原。

**失败定位：** 非法形状直接显示所需与实际元素数量；错位梯度显示两个坐标。

**通关成果：** 布局往返和梯度往返都通过，保存 Reshape 索引约定。

#### D03 向量混合器

## 原型实现顺序

| 优先级 | 先实现的画面能力 | 覆盖用途 |
| --- | --- | --- |
| 第一阶段 | 接线数值、样本表、残差曲线、梯度分解、训练阶段与损失曲线 | A 到 B 的 17 关真实训练闭环 |
