# UI 0.4：首次路线与新手实验验证

日期：2026-10-02。Unity 2022.3.62f1；Windows 64 位独立程序；包版本 0.4.0。0.3 的记录保存为 `ui-verification-0.3.md`。

## 本次实现

- 首次打开一页学习路线，说明最终目标、六个阶段、当前位置和第一个动作。
- P00 根据实际操作逐步提示：送样 → 训练 → 相同输入对比 → 验收解锁。
- 高亮真实按钮与仪表，可收起指引；主菜单与 F1 手册保留重看入口。
- 路线仅首次自动展示，旧存档保留完成记录、工作台、模块和训练后参数。
- P00 以约 4.4 秒展示 80 次真实 CPU 更新；默认学习率与显示统一为 0.2。
- 对比阶段保留平均训练损失曲线，单样本读数不混入；纸条显示预测与目标的绝对距离。
- 再启动训练或单步更新会撤销旧的比较完成状态，要求重新送样。

研究与详细流程见 [首次体验设计](onboarding-design.md)。
