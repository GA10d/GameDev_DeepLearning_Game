# Learning Foundry · UI 设计体系 v0.2

## 美学：实验设备和工程图纸

我们采用维修实验室的工具语言：石墨色设备框、温灰搪瓷面板、象牙白纸页、蓝灰线路、少量橙色标识。复古感来自结构、排版、接口和操作反馈。装饰必须说明它是什么物体，或帮助定位；大片纹理、无意义警告、虚构读数都不承担这个任务。

视觉关键词：精密、克制、能触摸、可检验。视角为清晰的正视工作台；模块有轻微厚度，线路和端口不受透视影响。主界面像打开一份维修档案，关卡图像设备路线图，编辑器像实验台，手册像技术页。

## 导航与信息分层

| 层 | 回答的问题 | 载体 | 显示时机 |
| --- | --- | --- | --- |
| 0 工坊 | 我继续哪个项目？ | 首页、章节路线、存档 | 离开当前任务时 |
| 1 委托 | 现在要造什么、怎样算成功？ | 顶部简短规格条 | 常驻，两行以内的核心目标；更多展开 |
| 2 装配 | 我把部件放在哪里、怎样接线？ | 中央画布＋左侧零件架 | 常驻，最大空间 |
| 3 对象 | 这个部件是什么、可调什么？ | 右侧属性检查器 | 选中时；未选中时显示本关实验设置 |
| 4 运行 | 哪一步发生了什么、为什么失败？ | 底部读数区、运行轨道 | 测量 / 调试 / 训练时展开 |
| 5 学习 | 我为何这样做？ | 手册抽屉、模块数据页 | 首次介绍或玩家主动打开 |

全局导航只保留工坊、章节、手册、设置。当前任务内部的装配 / 调试 / 训练不是三个独立页面；共享同一个模型和视口。保存、验收、导出是操作，不伪装成页面导航。

## 页面布局

### 工坊首页

左上是游戏标识和实验室编号；中心是一份当前委托和设备剪影；一个明显的“继续装配”。下方列最近项目和封装成果。设置、帮助、退出是弱入口。开发版范围说明放在小型版本区域，不能成为商业版的主视觉。

### 章节路线

左：章节清单，显示当前章节和下一个方向。中：当前章节的节点与依赖，已完成用勾号，可以进入用箭头，未解锁用锁与缺少的前置。右：所选关的知识点、任务、解锁部件和进入按钮。只有点击“进入”才切换任务，浏览节点不会弹窗口。

全树总览独立打开；跨章节前置在边界显示“来自 A07”并可跳转。依赖采用 AND；选修节点用虚线和“选修”文字，不能依赖颜色识别。完整树和章节视图必须使用同一份 `levels.json`。

### 装配工作台，1600 × 900 基准

| 区域 | 建议位置 / 尺寸 | 内容 |
| --- | --- | --- |
| 全局轨 | y=0，h=48 | 返回、设备名、章节、手册 |
| 规格条 | y=60，h=78 | 本关知识点；验收目标；新模块提示 |
| 零件架 | x=16，y=152，w=174 | 已解锁工具分组；图形＋短名；同组高度固定 |
| 画布 | x=204，y=152，w≈1068 | 可平移缩放；对象位置保持；小型缩放入口 |
| 属性区 | x≈1288，y=152，w≈296 | 当前对象 / 当前实验设置，独立于测量结果 |
| 读数区 | x=204，y≈656，h≈178 | 输入 / 输出对照、轨迹、错误、阶段 |
| 操作轨 | y=846，h=54 | 测量、下一样本、验收、弱工具；简短状态 |

装配时收起读数区，画布向下扩展。测量后展开结果；这只能改变视口高度，不能重排图、清空选择或重启训练。详细手册按需打开，关闭后保留视口、选择和未完成的接线状态。

### 调试与训练

调试：同一画布显示数值或梯度；底部选择“样本 / 轨迹 / 错误”，点击表格行定位对应对象。单步顺序对应实际计算顺序。仅有单个读数时显示一个点，不画下降曲线。

训练：保留模型位置；右侧设置学习率、训练预算、种子和批次，底部运行控件具有运行 / 暂停状态。曲线横轴是步骤，纵轴标明 loss 和线性 / 对数模式；训练与验证必须用文字和不同线型区分。参数动画服务于实际更新，不能凭装饰变化。

当前原型只有标量设备的 CPU 训练；卷积、批次、GPU、MNIST 页属于后续产品设计，必须标“规划”。GPU 选择将由运行后端真实能力决定。

### 手册和新模块

每个模块数据页只有五项：做什么、接口、最小例子、常见失败、由哪关解锁。公式附近配一个可改变数字的例子。正文不长期挤占装配区。

首次出现的新模块必须执行“概念短文 → 亲手使用 → 可观察反馈 → 验收”，登记在原有模块介绍表。底部按钮叫“回到装配”，避免把阅读当成考试。不能在某章直接多出没有介绍的 Dropout、Adam、BatchNorm 或张量操作。

## 视觉 tokens

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| Frame | `#283234` | 全局设备框、少量仪器底色 |
| Paper | `#F1F0E8` | 任务和手册 |
| Board | `#E1E5DF` | 工程画布 |
| Surface | `#D1D6CF` | 工具面板、部件外框 |
| Ink | `#263438` | 正文与数字 |
| Muted | `#586562` | 次级说明；不用于小尺寸关键读数 |
| Accent | `#AE4F24` | 当前选择、一个主要动作、编辑参数 |
| Signal | `#356877` | 前向连线和信号 |
| Gradient | `#796080` | 反向贡献；伴随箭头与 g 标签 |
| Passed | `#35654B` | 通过；伴随勾号 |
| Fault | `#A53F35` | 异常；伴随定位、文字和叉号 |

避免青色全屏发光、黑底半透明卡片墙、所有按钮同色、英文小标题堆砌、到处使用铆钉。圆角 0–2 px；只在实际旋钮和接头使用圆形。一般面板 1 px 分隔线；模块可有 2 px 底边厚度；仪器才有内嵌深色屏。

中文标题 / 正文：思源黑体 CN。数字、序列号、接口形状、公式中的拉丁变量：IBM Plex Mono。中文正文基准 18–20 px；标题 24–30 px；小标签 14–16 px；重要数值至少 18 px。数值右对齐、定宽列，固定单位与精度。科学计数法要明确，不能将微小 loss 四舍五入成零。

## 组件规则

| 组件 | 正常 | 选中 / 悬停 | 不可用 / 错误 |
| --- | --- | --- | --- |
| 关卡节点 | 编号＋名称＋一个知识点 | 左边橙条；右侧详情更新 | 锁＋缺少的前置；规划明确标注 |
| 零件条目 | 图形＋中文名，固定高度 | 描边；显示短公式或接口 | 锁定时显示解锁关，不能仅降透明度 |
| 标量模块 | 类型、名称、端口、读数 | 2 px 选择框；相关路径强调 | 端口旁错误短句；断线保持空插孔 |
| 参数模块 | 明确可调标记与值 | 检查器编辑；Enter 提交 | 无穷 / NaN 拒绝并保留旧值 |
| 封装盒 | 真实输入名＋模块名＋输出名 | 展开内部；面包屑返回 | 每个实例参数独立；形状错误定位到接口 |
| 端口 | 接口符号＋方向，命中范围 ≥28 px | 可连接目标明确高亮 | 原因说明：“需要 [B,16]，收到 [B,8]” |
| 线 | 2 px 实线，走线避让模块 | 当前路径 3 px；其它路径降低强调 | 分支有接点；普通相交不画接点 |
| 曲线 | 轴、单位、系列名、真实读数 | 悬停查看当前点与对应步骤 | 空状态写原因；异常保留最后有效点 |
| 验收报告 | 样本 / 预期 / 实际 / 误差 | 点行定位输出 | 失败内嵌报告；不重复弹出阻断窗口 |

端口类型后期至少覆盖标量、张量、梯度、控制；使用文字和形状同时编码。逐层封装后，模型画布展示模块结构，层内部才展示算术线路，避免 CNN 变成几千个小方块。

## 操作与状态

状态：Idle → Connecting / Editing → Measuring → Paused / Training → Checking → Passed / Fault。Connecting 可由 Esc 取消；训练中允许暂停、查看、记录，结构修改先暂停并使旧结果失效。调参后读数显示“待重新测量”，不能继续显示看似有效的旧结果。

优先键位：Ctrl+Z / Ctrl+Y、Delete、Esc、Home 适配全图、空格运行 / 暂停、F1 当前模块手册。输入框聚焦时不响应删除、空格和字母快捷键。最终键位可重映射；这些是产品目标，未在原型落实的项目见实施表。

连线：源端 → 目标端；预览线跟随指针；目标注明是否兼容；接入已有端口表示替换并可撤销。循环 / 类型不匹配时保留工作台并解释错误。拖拽部件不意外触发接线或打开属性页。

重置、覆盖存档等确认窗口与验收反馈区分。取消必须能完整回到先前状态。自动保存不弹 toast 打断操作，保存失败才给持久提示。

## 张量阶段的延伸

卷积模块显示输入 `[B,1,28,28]`、卷积核 `[8,1,3,3]`、输出 `[B,8,26,26]`；池化显示输出 `[B,8,13,13]`。形状数字只是示例，必须由真实后端计算。检查器展示当前样本和通道，热图有固定范围 / 当前范围切换与图例。

模型画布展示 Conv → 激活 → Pool → Flatten → Linear 的封装结构；检查器逐层看通道，打开层内部才看局部窗口和求和。MNIST 验收页展示同一张输入、预测概率、真实标签、混淆矩阵和错误样本；保留训练 / 验证 / 测试的来源标签。

首次出现 Conv、激活、Pool、Flatten、Softmax 或交叉熵，都仍遵循原关卡表的专门介绍。终局分类器是已理解部件的组合，不在最后一关突然引入新黑盒。

## 缩放、声音与可访问性

1600×900 为布局基准，必须检查 1280×720、1920×1080、2560×1440；字体缩放与画布缩放独立。小屏时收起属性区，结果区分页，不能仅把整个 UI 缩小。横向物理端口的有效命中范围不随画布缩放到不可点击。

背景静止；提示不闪烁。动效 80–160 ms；数据流动画只展示计算事件，并可减少动态。选择、插线、测量、完成使用不同短音效；不能把所有按钮都做成同一声高频蜂鸣。音效自行制作或取得可商用许可。

关键文字与背景目标对比度 ≥4.5:1；状态同时有文字 / 图形；键盘焦点可见。正式产品需增加键盘画布操作、提示阅读、可调整字号等能力。

## Unity 实施边界与优先级

本次包含调研、设计体系、可交互 HTML 样板、可分发字体，以及 Unity 第一轮 UI 改版。样板与实装范围以 `ui-verification.md` 的最终记录为准。

| 顺序 | 交付 | 必须保住的行为 |
| --- | --- | --- |
| P0 | 去除编辑页插画干扰；基础材质 / 字体；顶部规格、左零件、右属性、底读数；非阻断失败报告 | 既有 17 关的计算、通关、存档、撤销和封装 |
| P1 | 章节筛选、选中对象与数据联动、手册抽屉、画布视口保持 | 依赖逻辑与模块首次介绍，导入原存档 |
| P2 | 可调停靠布局、完整键盘 / 缩放适配、端口类型与图定位、层次封装 | 不改写实际计算或制造假曲线 |
| P3 | 张量 / CNN 可视化、后端能力选择、验证结果与分享 | 基于实际训练后端，规划能力不伪装成已实现 |

正式美术资源可以从这套框架提炼：部件面板九宫格、接头状态、旋钮、少量纸纹和机械声音。没有必要先买一套含几十种科幻框的 UI 包。

## 验收标准

观察 5 位目标玩家完成 A01、A04、B01、B09；记录第一次找到零件、第一次正确接线、第一次找到错误原因的时间和操作次数。设计目标：玩家在 10 秒内指出当前目标；失败后在两次操作内看到具体错误；查看手册后能回到原位置；运行与暂停明确。

工程验证：首关接线与通关流程、章节依赖、参数编辑、撤销 / 重置、选中模块时读数持续更新、训练暂停 / 继续、保存 / 恢复、无数据空状态、NaN / 断线状态。视觉验证：原生截图逐屏检查中文、数字、遮挡和对齐。用户测试尚未进行，不能把以上目标写成已获得的数据。
