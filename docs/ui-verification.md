# UI 0.3 实装与验证

日期：2026-10-02。Unity 2022.3.62f1；Windows 64 位独立程序；包版本 0.3.0。旧验证记录保存为 `ui-verification-0.2.md`。

## 本次实现

- 阅读 Mindustry、shapez、OpenTTD、OpenRCT2、OpenRA 官方仓库的固定提交，保存源文件 URL 与摘要清单。
- 工作台取代固定三栏，部件区分为输入端子、旋钮、运算芯片、模型盒和输出仪表。
- 原创程序绘制木台、工作垫、搪瓷外壳、倒角按钮、插孔、螺丝和线缆。
- 托盘拿取、鼠标跟随预览、重叠阻止、空位安装、取消放回、16 单位吸附。
- 接线头预览、实体线缆和端口提示；参数旋钮直接改变计算图的参数。
- 控制盒和示波器可开合、拖动；开合不重排装配区，选择部件不清除测量记录。
- 知识点仍在铭牌与关卡树；规格纸条与 F1 夹板手册提供完整教学和验收目标。

八张 1600×900 图片由实际 Unity UI 摄像机渲染到纹理。没有用网页重新拼出游戏截图。训练截图的模型为隔离诊断用例，整理了部件和器材位置；该模型执行真实 CPU 训练。预览安装图片为真实原生放置状态，使用同一个预览绘制方法指定测试指针位置。

`docs/ui-art-direction-preview.html` 直接显示这些图片。查看器的 13 项检查全部通过：原图尺寸、0.2 对照、滑杆、返回新版、标注、八种状态、无旧版预览时禁用对照、键盘切换、源码链接、窄窗口无横向溢出、标注与图片等比对齐、字体载入和无脚本错误。
