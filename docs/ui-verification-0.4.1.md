# UI 0.4.1：右键自由平移工作台

日期：2026-10-02。Unity 2022.3.62f1；Windows 64 位原生程序；包版本 0.4.1。此前教程的完整验证记录保留为 [0.4 验证](ui-verification-0.4.md)。

## 操作与实现

在工作垫内按住右键拖动，整体平移计算图；松开立即停止。可以从空白、部件、插孔或旋钮开始。参数、部件坐标和连接不因平移改变，控制盒与示波器留在原处。

右键单击在释放时放下零件或接线头。超过 Unity EventSystem 的拖动阈值后，手势视为平移，保留正在拿取的工具。部件、旋钮和浮动面板的正式拖动处理器只响应左键，避免右键误调参数或写入撤销记录。

新增 `WorkbenchPan.cs` 统一处理鼠标状态。只有初始命中工作垫及其子对象才捕获；被浮动面板、提示纸条或覆盖层挡住时不启动。手势从垫内开始后可拖出边界，直到释放；覆盖层出现或失去焦点时终止捕获。

指针先转成视口坐标，再移动内容位置，保持不同模型缩放下的拖动速度。工作垫使用 Unrestricted 运动、无惯性，移除有限滚动条的回写约束；地图和手册保留现有滚动方式。滚轮和左键拖动空白区继续可用。
