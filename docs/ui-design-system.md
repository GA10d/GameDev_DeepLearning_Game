# Learning Foundry · 游戏界面规范 0.4

本规范延续 Unity 0.3 的维修工作台，0.4 增加首次学习路线与 P00 现场指引。设计依据与具体源码位置见 [开源游戏源码调研](open-source-game-ui-study.md)，教程逻辑见 [首次体验设计](onboarding-design.md)。0.2 的规范保存在 `ui-design-system-0.2.md`，可用于比较。

## 首次体验层

0.4.1 补充画布导航：在工作垫内按住右键拖动，可从空白、部件、插孔或旋钮开始。缩放只改变模型大小，平移与鼠标移动保持一致。松开立即停止；单击右键仍放下工具，拖动保留手中的工具。器材和提示纸条自己接收鼠标，不随画布移动。工作垫不受有限滚动条边界限制；其他手册与地图的滚动保持原样。

首次路线用一张工坊图纸说明最终目标、六个学习阶段和下一动作，0.5所有阶段标为可玩。看过或跳过后，不再每次开工自动展示。

进入 P00 后，纸条一次只解释一个动作，以不拦截点击的遮暗和铜色边框指向真实按钮；运行中指向示波器。指引根据实际计算、训练、相同输入对比和验收推进。数值纸条始终容纳两行，区分训练平均损失与单个样本的绝对误差。

新手可以收起指引。主菜单和 F1 手册保留路线与操作重看入口，重看保留工作台参数和已完成记录。详细文案、状态和兼容策略见首次体验设计。

## 维修工作台的美学

玩家面对一张木质工作台，上面嵌入深绿装配垫。设备由低饱和搪瓷、铸件、黄铜插头、机械旋钮与发光读数器构成。不要把所有对象画成同一种矩形卡片，也不要让材质纹理盖过线路和数值。

部件身份先由轮廓和内部构造表达，再由文字确认。输入是短接线端子板；常量是固定值发生器；参数带可操作的旋钮；加法、乘法是切角芯片；封装模型是带接口和散热槽的盒子；输出是监测仪表。控制按钮有凸起与按下两种表面，窗口可伸缩的边缘使用九切片。

| 基础色 | 用途 |
|---|---|
| 木色 `#52412F` | 工作台环境，避免与数据争夺注意 |
| 工作垫 `#25342D` | 装配区域与稀疏定位点 |
| 框架 `#1A2621` | 铭牌、读数器的内腔 |
| 搪瓷 `#C7C4A6` | 部件外壳 |
| 金属 `#BABFAB` | 托盘、控制台、器材外壳 |
| 纸张 `#E3DBBF` | 委托规格、记录纸、技术手册 |
| 操作色 `#B56130` | 验收按钮、选中提示 |
| 磷光 `#B0DBA3` | 实际计算值与曲线 |

这些是程序的基础色，实际像素会受到倒角皮肤和表面纹理影响。可读性应检查最终渲染画面，不能只测基础色值。字体为 Source Han Sans CN 与 IBM Plex Mono，保留完整 OFL 授权文件。

## 工作台布局

参考分辨率为 1600×900，Unity CanvasScaler 按屏幕缩放。

| 载体 | 位置 / 尺寸 | 内容与状态 |
|---|---|---|
| 设备铭牌 | 左上 24,23 / 774×71 | 当前关卡与知识点 |
| 规格纸条 | 820,23 / 294×71 | 简短验收条件；点击打开完整手册 |
| 装配视口 | 36,125 / 1528×617 | 计算部件和接线；滚动、缩放 |
| 零件托盘 | 24,770 / 698×108 | 当前关卡的零件图标；参考关改为实验提示 |
| 控制台 | 740,770 / 836×108 | 送样、验收、撤销、重置、器材和知识入口 |
| 控制盒 | 默认 1246,139 / 294×438 | 可收起和拖动；选中校准或实验设置 |
| 示波器 | 默认 680,579 / 860×158 | 可收起和拖动；实际输出、曲线、参数记录 |
| 手册 | 362,63 / 876×776 | 夹板纸页，覆盖层，可滚动 |

控制盒和示波器是临时器材，开合不会改变装配视口的尺寸或滚动位置。选择部件只重建控制盒内容，不销毁测量记录。它们仍允许遮住部分装配区，由玩家移动或收起。训练截图里的器材位置与模块位置经过诊断用例整理，展示真实布局操作能力。

## 操作状态

| 状态 | 玩家动作 | 画面反馈 | 退出方式 |
|---|---|---|---|
| 空手 | 查看、点击、拖动部件 | 实体边缘提示；所选部件可打开校准盒 | 点击其他部件 |
| 拿取零件 | 托盘按钮或数字键 | 鼠标旁半透明部件；非法位置变红 | 空位左键安装；右键 / Esc 放回 |
| 拿取接线头 | 点击源部件右侧插孔 | 预览线跟随鼠标；输入插孔亮起 | 点击目标输入；右键 / Esc 取消 |
| 调参 | 上下拖动旋钮，Shift 微调 | 旋钮与真实数值更新；实际线路响应 | 松开；Ctrl+Z 撤销 |
| 校准 | 点击部件 | 小控制盒提供精确输入、拆卸和断线 | 关闭盒子或返回实验设置 |
| 实验 / 训练 | 操作控制盒 | 真实 CPU 更新与真实曲线 | 暂停、单步、预算结束 |
| 查阅知识 | F1、手册按钮或规格纸条 | 场景、新知识、玩法、完整规格、观察项、提示 | 返回装配，保留位置和读数 |

端口按钮的逻辑命中区域为 36×36，部件吸附网格为 16。缩放范围 0.45–1.3；全图功能按实际部件边界计算。小比例主要用于总览，精确读数和操作应放大。后续需要补充随缩放保持足够屏幕命中面积的端口、鼠标中键平移和更完整的键位配置。

输入层分别承担放置、端口接线、旋钮拖动、模块移动、器材移动。手册覆盖层或输入框获得焦点时，避免触发工作台快捷键。Space 送入样本，Tab 开合控制盒，F1 查阅本关知识，Ctrl+Z / Ctrl+Y 撤销与重做，Esc 放下工具并暂停训练。

## 教学与数据表达

保持原有 55 关关卡树、模块首次教学约束与逐关知识点。界面减少常驻段落，并不删去教学；知识点始终在铭牌，完整解释在本关手册，路线接点也显示知识点和前置条件。后续新模块仍须先介绍再解锁。

读数来自真实计算图；训练曲线来自实际训练记录。微小数值使用科学计数法。没有记录时显示等待状态，不绘制装饰性损失曲线。梯度展示与正向展示明确切换，不能把电路动效描述成 CPU/GPU 的实际执行可视化。

验收失败留在示波器和记录纸上；验收成功再展示结果并解锁下一份委托。当前错误信息仍以文字为主，尚未实装点击错误跳转到特定端口。

## 实现与交付边界

本轮新增的材质和几何由 `HardwareUI.cs` 独立生成，`WorkshopUI.cs` 实现实际部件和接线，`FoundryGame.cs` 组织游戏场景及工具状态。没有将第三方游戏源文件或精灵复制到 Unity 产品中。

0.3 已实现上述界面、原有 17 个关卡、真实标量 CPU 训练及新增放置/旋钮交互。GPU 训练、完整张量/CNN、MNIST 终章、Steam SDK、完整物件美术、音效库、手柄和超宽屏布局仍待开发。当前缩放适配不等于这些设备布局已经完成验收。

实际截图见 `ui-art-direction-preview.html`，新增交互与训练验证见 `ui-verification.md`。浏览器查看器展示原生图片，不模拟游戏操作。


0.5章节补全采用顺序张量积木工作垫、常驻训练开关、形状读数、可点击张量格、特征/梯度图、决策边界、混淆矩阵和手写板。每个新模块安装后在控制柜展示说明，F1记录当关知识与操作。详见 [55关试玩说明](campaign-playable-v05.md)。
